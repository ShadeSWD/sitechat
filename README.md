# sitechat — селфхостед чат-помощник для сайтов

Один лёгкий сервис (Flask + локальная LLM через Ollama) обслуживает чат-виджеты
сразу нескольких сайтов. Без внешних API, без платных сервисов, без телеметрии —
всё считается на своём сервере.

## Как устроено

- `knowledge/<site>.md` — справка о сайте; системный промпт запрещает модели
  выдумывать и уводить разговор от тематики сайта.
- `POST /chat` `{site, message, history}` → ответ локальной модели
  (qwen2.5:3b по умолчанию, ~2 ГБ RAM); история диалога живёт на клиенте.
- `GET /widget.js` — встраиваемый виджет (плавающая кнопка, ванильный JS,
  ~3 КБ): `<script src="/sitechat/widget.js" data-site="mysite" defer></script>`.
- Защита: лимит запросов на IP, ограничение длин, только известные site-ключи,
  деградация с честным сообщением при недоступности модели.
- Подключение нового сайта = один markdown-файл + одна строка в шаблоне
  (или nginx `sub_filter`, если код сайта трогать нельзя).

## Продакшен

Работает на VPS (4 vCPU/16 GB, без GPU) на трёх сайтах: научный инструментарий
многокритериального выбора, решатель курсовых по деталям машин (виджет внедрён
через nginx sub_filter без правки чужого кода), карта GPS-треков. Ollama делит
модель с соседним AIOps-агентом (aiops-sentinel).

## Запуск

```bash
python3 -m unittest discover tests     # 7 тестов (LLM мокается)
gunicorn -b 127.0.0.1:8075 -w 2 --timeout 240 sitechat.app:app
# nginx: location /sitechat/ { proxy_pass http://127.0.0.1:8075/; }
```
