Сайт: Редуктор Онлайн — https://shadeswd.duckdns.org/reduktor/
Автоматический решатель курсового проекта по деталям машин: расчёт привода с
редуктором по исходным данным (мощность, обороты, схема): кинематический расчёт,
выбор электродвигателя, зубчатые передачи, валы, подшипники, шпонки, корпус,
SVG-чертежи. Поддерживает варианты заданий (сетка 10×10) и произвольные данные.
Проектные развилки (выбор двигателя, разбивка передаточного числа, материал колёс,
форма корпуса) решаются многокритериально через API сайта Relation Metrics.
